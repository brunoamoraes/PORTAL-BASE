Aula 06

CSS: aparência e identidade

Conecte o CSS ao HTML, use seletores e compreenda o box model para controlar a apresentação da página.

Área: Linguagem de Marcação

Nível: Inicial

Checkpoint: 5 questões

Briefing

O mesmo HTML, outro mundo

A estrutura do laboratório permanece intacta, mas sua aparência precisa mudar completamente. É aqui que o CSS demonstra por que estrutura e apresentação devem trabalhar separadas.

01 · Conteúdo

Como o CSS encontra os elementos

Seletor de elemento

p { ... } aplica regras a todos os parágrafos.

Classe

.destaque { ... } pode ser reutilizada em vários elementos.

ID

#portal { ... } identifica um elemento específico. Evite transformar IDs em padrão de estilização repetitiva.

CSS externo

<link rel="stylesheet" href="css/style.css"> mantém o projeto organizado.

02 · Box Model

Todo elemento ocupa espaço

O box model organiza o elemento em conteúdo → padding → border → margin. Entender isso evita layouts “misteriosamente desalinhados”.

CONTEÚDO

O padding cria espaço interno. A borda contorna a caixa. A margem afasta a caixa dos outros elementos.

04 · Organização

Um arquivo CSS bem estruturado

/* style.css */
body {
  font-family: Arial, sans-serif;
  background: #10151b;
  color: #f4f4f4;
}

.card {
  padding: 24px;
  border: 1px solid #39424d;
  border-radius: 16px;
}

05 · Sua missão

Do HTML cru ao portal

Pegue a estrutura semântica produzida nas aulas anteriores e crie um arquivo CSS externo. Defina tipografia, cores, espaçamento, bordas e estados básicos de links e botões sem alterar o significado do HTML.

Boss Challenge

CSS impossível de manter

Um site possui estilos inline em quase todos os elementos, IDs usados para tudo e valores diferentes de espaçamento em cada seção. Reorganize a estratégia pensando em reutilização, classes e consistência.
