Aula 10

Do wireframe ao HTML semântico

Leia a intenção visual do protótipo e converta cada região em uma estrutura HTML com significado.

Área: Linguagem de Marcação

Foco: Implementação

Checkpoint: 5 questões

Briefing

O desenho agora precisa virar código

Não copie apenas a aparência. Interprete a função de cada região do wireframe e escolha elementos semânticos adequados: header, nav, main, section, article, aside e footer.

01 · Tradução

Do bloco visual para a tag

Topo institucional<header>
Links principais<nav>
Conteúdo central<main>
Grupo temático<section>
Conteúdo independente<article>
Apoio complementar<aside>
Informações finais<footer>
Use <div> apenas quando não houver um elemento semântico que represente corretamente a função daquele bloco.

02 · Laboratório

HTML Translator

Escreva a estrutura correspondente ao wireframe apresentado. O laboratório avalia a presença das regiões semânticas.

HEADER
NAV
SECTION
ASIDE
FOOTER
A análise verificará semântica e uso excessivo de DIV.

03 · Exemplo

Estrutura base

<body>
  <header>
    <h1>Portal Escolar</h1>
    <nav>...</nav>
  </header>

  <main>
    <section>
      <h2>Destaques</h2>
      <article>...</article>
    </section>
    <aside>...</aside>
  </main>

  <footer>...</footer>
</body>

04 · Sua missão

Implemente seu protótipo

Use o protótipo da Aula 09 como referência e crie a estrutura HTML da página. Primeiro implemente apenas a semântica e o conteúdo; deixe o CSS para a próxima etapa de refinamento.

Boss Challenge

O império das DIVs

Você recebeu uma página construída quase totalmente com <div>. Reescreva a estrutura utilizando elementos semânticos e explique por que cada substituição melhora o documento.
