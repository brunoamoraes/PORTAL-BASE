Briefing

Mensagem do Hawkins Lab

O Laboratório Hawkins detectou um portal digital instável. Antes de interagir com ele, você precisa identificar quem transporta os dados, quem interpreta a página e qual tecnologia cuida de cada camada.

01 · Conteúdo

Introdução à Web

Internet

Infraestrutura mundial de redes que conecta dispositivos e transporta dados.

Web

Serviço que utiliza a Internet para disponibilizar páginas e aplicações acessadas por navegadores.

Navegador

Programa que solicita recursos a servidores e interpreta HTML, CSS e JavaScript.

Servidor

Computador ou serviço que responde às requisições enviando páginas, arquivos ou dados.

HTML

Estrutura e significado do conteúdo.

CSS

Aparência, cores, tipografia e layout.

JavaScript

Comportamento e interatividade.

Regra do Hawkins Lab: HTML estrutura o mundo, CSS muda sua aparência e JavaScript faz as coisas acontecerem.

03 · Sua missão

Aplicação prática

Liste três sites que você utiliza, identifique uma função visível de HTML, uma de CSS e uma de JavaScript em cada um e abra o DevTools (F12) para observar o documento.

Boss Challenge

Falha no portal

Um colega afirma que “Internet e Web são a mesma coisa” e que “HTML é uma linguagem de programação”. Explique por que as duas afirmações estão incorretas.
