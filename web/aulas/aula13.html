Briefing

Ative o portal com JavaScript

HTML já estruturou a interface e CSS definiu sua aparência. Agora JavaScript permitirá localizar elementos, ouvir eventos e alterar o DOM.

01 · Conteúdo

Primeiros comandos de interação

const / let

Armazenam referências e valores utilizados pelo programa.

querySelector()

Localiza um elemento usando seletor CSS.

addEventListener()

Executa uma função quando um evento acontece.

classList

Adiciona, remove ou alterna classes CSS.

const portal = document.querySelector('#portal');

portal.addEventListener('click', () => {
  document.body.classList.toggle('upside-down');
});
