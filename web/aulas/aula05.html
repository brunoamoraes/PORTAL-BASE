Briefing

Arquivo recuperado do laboratório

Uma sequência de imagens foi encontrada nos computadores de Hawkins. Algumas são fotografias, outras ícones e outras fazem parte apenas do cenário. Sua missão é escolher o formato e a forma de uso corretos.

01 · Conteúdo

Imagem também comunica

<img>

Use quando a imagem faz parte do conteúdo. Os atributos essenciais são src e alt.

background-image

Use no CSS quando a imagem é decorativa ou compõe o fundo visual de um elemento.

Caminhos

imagens/foto.webp, ../assets/img/icone.svg e URLs absolutas apontam para origens diferentes.

Texto alternativo

O alt descreve conteúdo relevante e ajuda quando a imagem não carrega ou é lida por tecnologia assistiva.

Regra prática: se retirar a imagem muda o significado do conteúdo, ela provavelmente merece <img> e um alt útil.

02 · Formatos

Qual arquivo usar?

JPEG / JPG

Bom para fotografias e imagens com muitas variações de cor. Não oferece transparência.

PNG

Útil quando transparência é importante. Pode gerar arquivos maiores.

SVG

Vetor escalável, excelente para ícones, logotipos e formas simples.

WebP

Formato moderno com boa compressão para imagens da Web.
