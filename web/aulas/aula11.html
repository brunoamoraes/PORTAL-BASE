Flexbox

Alinhamento, distribuição, eixos e responsividade.

Área: Linguagem de Marcação

Foco: Layout

Checkpoint: 5 questões

Briefing

Organize o laboratório sem empilhar DIVs

Flexbox organiza elementos em um eixo e permite controlar alinhamento, distribuição e espaçamento com poucas regras CSS.

01 · Conteúdo

Contêiner e itens flexíveis

display: flex

Transforma os filhos diretos em itens flexíveis.

flex-direction

Define o eixo principal: row, row-reverse, column ou column-reverse.

justify-content

Distribui os itens no eixo principal.

align-items

Alinha os itens no eixo transversal.

gap

Cria espaçamento consistente entre os itens.

flex-wrap

Permite quebra de linha quando não há espaço suficiente.
