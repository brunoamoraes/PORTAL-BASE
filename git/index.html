CARTAS DE CONHECIMENTO

Git & GitHub na prática

Arena 01 · Fundamentos

Configurar sua identidade

Defina nome e e-mail usados nos commits.

git config --global user.name "Seu Nome"
git config --global user.email "email@exemplo.com"
Quando usar?

Na primeira configuração do Git em um computador ou ao corrigir a autoria dos commits.

Arena 01 · Fundamentos

git init

Transforma uma pasta comum em um repositório Git.

git init
Como conferir?

Execute git status. O Git passa a acompanhar a pasta e cria internamente o diretório .git.

Arena 01 · Fundamentos

git status

Mostra o estado dos arquivos e da área de preparação.

git status
Dica

É um dos comandos mais seguros para executar quando você não sabe em que estado o repositório está.

Arena 02 · Commits

git add

Envia alterações para a Staging Area antes do commit.

git add .
# ou
git add index.html
O que o ponto faz?

git add . adiciona as alterações do diretório atual e abaixo dele para preparação.

Arena 02 · Commits

git commit

Registra uma versão das alterações preparadas.

git commit -m "feat: cria página inicial"
Boa prática

Use uma mensagem curta que explique o que mudou, e não apenas “alterações”.

Arena 02 · Commits

Histórico de commits

Consulte a linha do tempo do projeto.

git log --oneline --graph --decorate
Para que serve?

Ajuda a localizar commits, entender branches e identificar onde uma mudança entrou.

Arena 03 · Branches

Criar uma branch

Crie uma linha de desenvolvimento independente.

git switch -c feature/login
Listar branches
git branch
Arena 03 · Branches

Trocar de branch

Use switch para navegar entre branches.

git switch main
git switch feature/login
E o checkout?

git checkout ainda existe, mas git switch deixa a intenção de troca de branch mais clara.

Arena 03 · Branches

Mesclar branches

Traga alterações de uma branch para outra.

git switch main
git merge feature/login
Antes do merge

Confirme a branch atual com git status e prefira estar com o trabalho salvo em commits.

BOSS · Conflitos

Resolver conflito de merge

O Git não conseguiu escolher automaticamente qual versão manter.

git status
# edite os arquivos em conflito
git add arquivo.html
git commit
Procure no arquivo

Os marcadores <<<<<<<, ======= e >>>>>>> mostram os trechos que precisam de decisão.

Arena 04 · GitHub

Clonar um repositório

Cria uma cópia local de um projeto remoto.

git clone URL_DO_REPOSITORIO
Depois do clone

Entre na pasta criada com cd nome-do-repositorio e confira git status.

Arena 04 · GitHub

Conectar ao GitHub

Associe o repositório local a um remoto.

git remote add origin URL_DO_REPOSITORIO
git remote -v
O que é origin?

É o nome convencional dado ao repositório remoto principal.

Arena 04 · GitHub

git push

Envia commits locais ao GitHub.

git push -u origin main
Depois da primeira vez

Quando o upstream estiver configurado, normalmente basta executar git push.

Arena 04 · GitHub

git pull

Busca alterações do remoto e tenta integrá-las à branch atual.

git pull origin main
Antes de usar

Confira se você possui alterações locais não salvas. Em projetos colaborativos, faça pull com frequência.

Arena 04 · GitHub

git fetch

Atualiza informações do remoto sem alterar seus arquivos de trabalho.

git fetch origin
Pull x fetch

fetch apenas busca referências; pull busca e integra as alterações.

Arena 04 · Git

Guardar alterações temporárias

Use stash quando precisa interromper um trabalho ainda não commitado.

git stash
git stash pop
Quando ajuda?

Por exemplo, quando você precisa trocar de branch rapidamente sem criar um commit incompleto.

Arena 04 · Recuperação

git restore

Restaura arquivo modificado para a versão registrada.

git restore arquivo.html
Atenção

Alterações locais não commitadas podem ser perdidas. Confirme antes de executar.

Arena 04 · Recuperação

git revert

Cria um novo commit que desfaz as mudanças de outro commit.

git revert HASH_DO_COMMIT
Quando preferir?

É adequado para histórico já compartilhado, pois não reescreve os commits anteriores.

Arena 04 · Recuperação

git reset

Move o ponteiro da branch e pode alterar staging/arquivos conforme o modo.

git reset --soft HEAD~1
⚠ Cuidado

--hard pode apagar alterações locais. Em histórico compartilhado, considere git revert.

Arena 04 · Projeto limpo

.gitignore

Evite versionar arquivos gerados, dependências e dados locais.

node_modules/
.env
.DS_Store
Importante

Não use .gitignore como única proteção para segredos que já foram commitados. Credenciais expostas devem ser revogadas.

Arena 05 · Colaboração

GitHub Issues

Registre bugs, tarefas, ideias e critérios de aceite.

Boa estrutura

Título claro + contexto + passos/requisitos + resultado esperado + evidências quando necessário.

Arena 05 · Colaboração

Pull Request

Propõe integrar alterações de uma branch e permite revisão antes do merge.

Fluxo

Branch → commits → push → Pull Request → revisão → ajustes → merge.

Arena 05 · Colaboração

Fork

Cria uma cópia de um repositório na sua conta do GitHub para desenvolver independentemente.

Uso comum

Contribuições em projetos nos quais você não possui permissão direta de escrita.

Arena 06 · Deploy

GitHub Pages

Publique sites estáticos diretamente de um repositório.

  1. Settings → Pages
  2. Deploy from a branch
  3. Escolha main e /(root)
  4. Mantenha index.html na raiz publicada
Dica para links

Em project pages, prefira caminhos relativos como web/index.html em vez de caminhos iniciados por /.

Boss · Erros comuns

Push rejeitado / histórico remoto mudou

O remoto possui commits que sua branch local ainda não tem.

git status
git pull --rebase origin main
# resolva conflitos se houver
git push origin main
Não force sem entender

Evite git push --force em branches compartilhadas. Ele pode sobrescrever histórico remoto.

Boss · Erros comuns

“Not a git repository”

Você provavelmente está fora da pasta que contém o repositório.

git rev-parse --show-toplevel
Se falhar

Navegue com cd até a pasta correta ou inicialize um novo repositório somente se isso for realmente a intenção.

Arena 06 · Conta

Autenticação com GitHub

Operações Git por HTTPS não usam a senha comum da conta como credencial Git.

Opções

Use Git Credential Manager, token quando aplicável ou configure uma chave SSH. Nunca coloque tokens dentro do código ou do repositório.
