O início, a configuração e a instalação de um Banco de Dados

Prepare o ambiente de trabalho, compreenda o papel do SGBD e organize a base necessária para começar um projeto de dados.

Nível: Inicial

Objetivo: Ambiente e configuração

Checkpoint: 5 questões

Briefing

Antes de criar tabelas, prepare o ambiente

Um banco de dados precisa de um SGBD corretamente instalado e configurado. Nesta aula você identifica os componentes do ambiente, entende servidor, cliente e conexão e organiza um fluxo seguro de trabalho.

01 · Conteúdo

O que precisa existir?

SGBD

Software responsável por armazenar, consultar, proteger e administrar os dados.

Servidor

Processo que mantém o banco disponível para conexões e execução de comandos.

Cliente

Ferramenta usada para se conectar ao SGBD e executar SQL, como terminal ou interface gráfica.

Conexão

Combinação de host, porta, usuário, senha e banco utilizada para acessar o ambiente.

02 · Preparação

Fluxo recomendado

  1. Instalar o SGBD definido para a aula.
  2. Confirmar se o serviço está em execução.
  3. Criar ou validar o usuário de acesso.
  4. Testar a conexão por terminal ou ferramenta gráfica.
  5. Organizar uma pasta de scripts SQL do projeto.
  6. Registrar configurações importantes sem expor senhas em arquivos públicos.
Checkpoint técnico: antes de modelar ou executar DDL, confirme que você consegue conectar e executar uma consulta simples no ambiente.

03 · Laboratório

Diagnóstico do ambiente

Responda mentalmente: o SGBD está instalado? O serviço está ativo? Você sabe qual host e porta utiliza? Consegue autenticar? O banco de testes está acessível?

04 · Sua atividade

Documente seu ambiente

  1. Identifique o SGBD utilizado.
  2. Registre a ferramenta cliente.
  3. Anote host e porta sem registrar credenciais secretas.
  4. Execute uma conexão de teste.
  5. Crie uma pasta para guardar os scripts SQL da disciplina.
