Briefing

Objetivo da missão

Avance pelo conteúdo, execute os exemplos no MySQL e registre as decisões técnicas. O foco é compreender o motivo das escolhas, não apenas reproduzir comandos.

ETAPA 01

Auditoria de estrutura

Antes de criar índices, identifique redundâncias, grupos repetitivos e dependências inadequadas.

Primeiro corrigimos o significado e a estrutura dos dados. Depois pensamos em velocidade.

ETAPA 02

1FN — valores atômicos

Elimine colunas repetitivas como produto1, produto2 e produto3. Use uma tabela associativa para representar itens.

PEDIDO 1 ── N ITEM_PEDIDO N ── 1 PRODUTO

ETAPA 03

2FN e 3FN

Separe atributos que dependem apenas de parte da chave e remova dependências transitivas.

Fornecedor, Produto e Categoria devem possuir responsabilidades próprias.

ETAPA 04

INDEX

Crie índices apenas após entender as consultas reais do sistema.

CREATE INDEX idx_produto_nome ON produto(nome);
CREATE INDEX idx_pedido_cliente_data ON pedido(id_cliente, data_pedido);

ETAPA 05

EXPLAIN

Use EXPLAIN para observar como o MySQL pretende executar uma consulta.

EXPLAIN SELECT * FROM produto WHERE nome LIKE 'Cap%';
