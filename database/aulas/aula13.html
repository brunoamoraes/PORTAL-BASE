Stored Procedures

Automatizando operações e regras de negócio no SmartCoffee.

Briefing

Objetivo da missão

Avance pelo conteúdo, execute os exemplos no MySQL e registre as decisões técnicas. O foco é compreender o motivo das escolhas, não apenas reproduzir comandos.

ETAPA 01

DELIMITER e estrutura

Stored Procedure é uma rotina armazenada que pode receber parâmetros, processar regras e devolver resultados.

DELIMITER $$
CREATE PROCEDURE listar_produtos()
BEGIN
  SELECT * FROM produto;
END $$
DELIMITER ;

ETAPA 02

Parâmetros IN e OUT

IN recebe valores; OUT permite devolver resultados ao chamador.

CALL contar_produtos_ativos(@total);
SELECT @total;

ETAPA 03

Variáveis e SELECT INTO

Use DECLARE para variáveis locais e SELECT ... INTO para carregar valores.

DECLARE v_preco DECIMAL(10,2);
SELECT preco INTO v_preco FROM produto WHERE id_produto = p_id_produto;

ETAPA 04

IF / ELSEIF / ELSE

Procedures podem tomar decisões com base em dados e parâmetros.

IF v_quantidade = 0 THEN
  SELECT 'SEM ESTOQUE';
ELSEIF v_quantidade <= 5 THEN
  SELECT 'ESTOQUE BAIXO';
ELSE
  SELECT 'ESTOQUE NORMAL';
END IF;

ETAPA 05

Procedure de negócio

Integre INSERT, UPDATE, variáveis e transações em processos como criação de pedido, fidelidade e atualização de estoque.

VIEW = consulta armazenada. PROCEDURE = processo armazenado.
