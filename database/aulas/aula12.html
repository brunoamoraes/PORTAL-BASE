Views

Criando visões reutilizáveis e relatórios no SmartCoffee.

Briefing

Objetivo da missão

Avance pelo conteúdo, execute os exemplos no MySQL e registre as decisões técnicas. O foco é compreender o motivo das escolhas, não apenas reproduzir comandos.

ETAPA 01

Conceito

Uma VIEW é uma consulta armazenada que pode ser utilizada como uma tabela virtual.

CREATE VIEW vw_produtos_ativos AS
SELECT id_produto, nome, preco
FROM produto
WHERE ativo = TRUE;

ETAPA 02

JOIN em Views

Uma VIEW pode reunir dados de várias tabelas e simplificar relatórios.

CREATE VIEW vw_pedidos_clientes AS
SELECT p.id_pedido, c.nome, p.data_pedido
FROM pedido p
JOIN cliente c ON c.id_cliente = p.id_cliente;

ETAPA 03

Agregações

Views podem encapsular COUNT, SUM, AVG e GROUP BY para relatórios.

VIEW representa uma consulta, não um processo.

ETAPA 04

Gerenciamento

Use SHOW CREATE VIEW, CREATE OR REPLACE VIEW e DROP VIEW para manter as visões.

SHOW CREATE VIEW vw_produtos_ativos;
DROP VIEW IF EXISTS vw_produtos_ativos;

ETAPA 05

Cuidados

Views não substituem índices e nem sempre são atualizáveis. Avalie o objetivo de cada camada.
