Briefing

A base precisa sair do projeto

Até aqui você modelou. Agora o SGBD precisa receber instruções para criar banco, tabelas e estruturas. DDL — Data Definition Language — é o conjunto de comandos responsável por definir e alterar essa estrutura.

01 · Conteúdo

Principais comandos DDL

CREATE

Cria estruturas.

CREATE DATABASE smartcoffee;

ALTER

Altera uma estrutura existente.

ALTER TABLE produto ADD estoque INT;

DROP

Remove a estrutura inteira.

DROP TABLE produto;

TRUNCATE

Remove os registros da tabela mantendo sua estrutura.

TRUNCATE TABLE produto;

02 · Demonstração

Criando a tabela PRODUTO

CREATE TABLE produto (
  id_produto INT PRIMARY KEY AUTO_INCREMENT,
  nome_produto VARCHAR(100) NOT NULL,
  descricao VARCHAR(255),
  preco DECIMAL(10,2) NOT NULL,
  id_categoria INT NOT NULL
);
Importante: na Missão 07 vamos aprofundar as constraints e transformar esse modelo em uma estrutura com regras de integridade completas.

04 · Comparação

DROP não é TRUNCATE

DROP TABLE

Remove a tabela e sua definição. Depois do comando, a estrutura deixa de existir.

TRUNCATE TABLE

Remove os registros, mas mantém a tabela pronta para receber novos dados.
