Missão 09

Manipulação de Recursos

Insira, altere e remova dados do SmartCoffee com segurança usando INSERT, UPDATE e DELETE.

Nível: Intermediário

Objetivo: DML

Checkpoint: 5 questões

Briefing

O banco agora está vivo

Até aqui você estruturou e consultou dados. Nesta missão, cada comando passa a alterar o estado da base. Por isso, leitura cuidadosa, cláusulas WHERE e validação antes da execução tornam-se essenciais.

01 · Conteúdo

Os três comandos centrais do DML

INSERT

Adiciona novos registros.

INSERT INTO produto (nome, preco, estoque) VALUES ('Mocha', 14.90, 8);

UPDATE

Altera registros existentes. Use WHERE para limitar o alvo.

UPDATE produto SET preco = 15.90 WHERE id_produto = 3;

DELETE

Remove registros. Sem WHERE, todos os registros da tabela podem ser afetados.

DELETE FROM produto WHERE id_produto = 3;

Transação mental

Antes de alterar dados, confirme: tabela correta, campos corretos, condição correta e impacto esperado.

SELECT ... WHERE ... antes de UPDATE ou DELETE.

Protocolo de segurança: antes de executar UPDATE ou DELETE em um banco real, rode primeiro um SELECT com o mesmo WHERE para conferir exatamente quais registros serão afetados.

02 · Demonstração

Fluxo seguro no SmartCoffee

-- 1. conferir o alvo
SELECT * FROM produto WHERE id_produto = 2;

-- 2. alterar somente o registro esperado
UPDATE produto
SET estoque = 20
WHERE id_produto = 2;

-- 3. conferir o resultado
SELECT * FROM produto WHERE id_produto = 2;

Boss Challenge

Reajuste controlado

O SmartCoffee precisa reajustar em 10% apenas os produtos com preço abaixo de R$ 10. Escreva o UPDATE adequado e, antes dele, um SELECT que mostre os registros que serão afetados.

Ver estratégia
