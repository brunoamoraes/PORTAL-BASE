Briefing

Mensagem do Command Center

Uma base recebeu milhares de registros de clientes, produtos e pedidos. Sem organização, esses registros são apenas dados dispersos. Sua primeira missão é compreender como armazená-los de maneira estruturada, segura e útil.

01 · Conteúdo

Dados, informação, banco de dados e SGBD

Dado

Um valor isolado, ainda sem interpretação completa. Ex.: 12, Maria, 2026-10-05.

Informação

Dados organizados e contextualizados. Ex.: “Maria realizou 12 pedidos em outubro”.

Banco de Dados

Coleção organizada de dados relacionados, preparada para cadastro, consulta, atualização e exclusão controlada.

SGBD

Sistema Gerenciador de Banco de Dados: software que permite criar, administrar, proteger e consultar bancos de dados.

Nota do comandante: MySQL, PostgreSQL e SQLite são exemplos de SGBDs que serão utilizados como referência ao longo da trilha.

02 · Comparação

Relacional × Não relacional

Banco relacional

Organiza dados em tabelas relacionadas por chaves. É adequado quando estrutura, integridade e relacionamentos são importantes.

  • Tabelas
  • Linhas e colunas
  • PK e FK
  • SQL

Banco não relacional

Pode armazenar documentos, chave-valor, grafos ou outras estruturas. É útil em cenários que pedem flexibilidade ou escala específica.

  • Documentos
  • Chave-valor
  • Grafos
  • Estruturas flexíveis
