Missão 10 · Operação Final

SmartCoffee Control

Una modelagem, SQL e interface web em uma aplicação visual de cadastro e gerenciamento de produtos.

Nível: Aplicação

Objetivo: CRUD

Tecnologias: HTML + CSS + JS + SQL

Briefing

Do banco para a aplicação

O CRUD conecta ações de interface às operações de dados: Create → INSERT, Read → SELECT, Update → UPDATE e Delete → DELETE. Nesta versão, a aplicação funciona no navegador para demonstrar o fluxo antes da conexão com MySQL/Node.js.

01 · Arquitetura

O caminho de uma ação

HTMLformulário e tabela
→
JavaScriptcaptura a ação
→
Backendvalida e executa
→
MySQLpersiste os dados
Nesta simulação, o JavaScript substitui temporariamente o backend e o banco real. Assim o aluno entende o CRUD visualmente antes de trabalhar com conexão, rotas e persistência.

03 · SQL equivalente

O que aconteceria no banco?

Create

INSERT INTO produto
(nome, preco, estoque)
VALUES (?, ?, ?);

Read

SELECT *
FROM produto
ORDER BY nome;

Update

UPDATE produto
SET nome=?, preco=?, estoque=?
WHERE id_produto=?;

Delete

DELETE FROM produto
WHERE id_produto=?;

04 · Sua missão

Transforme a simulação em sistema

  1. Cadastre pelo menos quatro produtos de categorias diferentes.
  2. Edite preço e estoque de um produto.
  3. Exclua um item e observe a atualização dos indicadores.
  4. Relacione cada botão da interface ao comando SQL correspondente.
  5. Desenhe o fluxo futuro: formulário → JavaScript → rota Node.js → MySQL → resposta → atualização da interface.

Boss Challenge Final

CRUD real com MySQL

Quando avançarmos para integração real, esta mesma interface poderá chamar uma API Node.js. O objetivo será substituir o armazenamento local por rotas GET, POST, PUT e DELETE conectadas ao banco SmartCoffee.
